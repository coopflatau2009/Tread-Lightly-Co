# Tread Lightly Co.

This is a clean, GitHub Pages-ready static website for Tread Lightly Co.

## Files included
- `index.html` – home page
- `gear.html` – gear category overview
- `all-gear.html` – all gear landing page
- `hats.html` – hats page
- `tees.html` – tees page
- `hoodies.html` – hoodies page
- `accessories.html` – accessories page
- `story.html` – brand story page
- `product-sweatshirt.html` – placeholder product page
- `style.css` – site styling
- `script.js` – mobile navigation toggle

## GitHub Pages setup
1. Push these files to the `main` branch of your repository.
2. In GitHub, go to Settings → Pages.
3. Set the source to `Deploy from a branch`.
4. Choose the `main` branch and the `/ (root)` folder.
5. Save.

Your site will be published at:
`https://yourusername.github.io/Tread-Lightly-Co/`
